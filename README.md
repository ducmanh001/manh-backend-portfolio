# Phan Van Manh — Backend Developer Portfolio

Personal portfolio site for **Phan Van Manh**, Backend Software Engineer (Node.js, NestJS, PostgreSQL).

Static site — plain HTML/CSS/JS, no build step required.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Structure

- `index.html` — page markup
- `assets/css/styles.css` — styles
- `assets/js/main.js` — nav, theme toggle, scroll reveal, contact form
- `assets/cv/` — downloadable CV (PDF)
